💡 Flow Architecture & Field Source

In Ninja, a Flow is a reusable configuration that defines your verification rules. For Pre-filled sessions, we set source: "business" so Ninja knows our backend provides the player's name & DOB when generating links — skipping form entry directly into live biometric verification.
